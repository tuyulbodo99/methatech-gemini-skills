# methatech-gemini-skills

Skill untuk Gemini dan Gem "MethaTech AI Architect": sandbox, SSH VPS, API MethaTech, dan skill kerja lainnya.

## Cara pakai di Gemini

Tempel petunjuk ini di kolom Petunjuk Gem (atau di info yang diingat Gemini):

> Semua skill saya ada di repo ini: https://github.com/tuyulbodo99/methatech-gemini-skills — Sebelum menjawab, buka dulu repo itu. Kalau tugas saya cocok dengan salah satu skill di folder skills/, baca file SKILL.md-nya lewat https://raw.githubusercontent.com/tuyulbodo99/methatech-gemini-skills/main/skills/<nama-skill>/SKILL.md dan ikuti langkahnya persis. Daftar skill dan kapan dipakainya ada di petunjuk-gem.md di repo yang sama.

## Isi repo

- `skills/` — 42 skill, masing-masing folder berisi `SKILL.md`.
- `petunjuk-gem.md` — petunjuk lengkap untuk Gem (aturan manggil skill + daftar skill).

## Skill utama

- `novita-sandbox` — buka sandbox Novita untuk tugas yang butuh mesin Linux.
- `sevalla-ssh` — masuk dan kelola VPS mini Sevalla (ssh.danamain.xyz).
- `methatech-api` — panggil API MethaTech (daftar model, chat dengan model).

Kunci dan password TIDAK disimpan di repo ini. Isi sendiri di tempat yang sudah ditandai saat memakai skill.
